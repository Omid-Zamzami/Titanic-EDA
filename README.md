# Titanic-EDA

An exploratory data analysis (EDA) of the Titanic passenger dataset. The project cleans the raw data with a reusable Python pipeline, then provides an interactive command-line visualizer to explore which demographic and socioeconomic factors affected a passenger's chance of survival.

## Overview

The project has three parts:

1. **Exploratory analysis** in a Jupyter notebook that documents each step, from data inspection to statistical findings.
2. **A reusable cleaning module** (`src/clean_data.py`) that validates the data, removes duplicates, imputes missing values, and engineers cabin features. It saves the cleaned dataset to `data/`.
3. **An interactive visualizer** that runs after cleaning and lets you choose from seven survival charts in the terminal.

## Key Findings

- **Overall survival:** 38.4% of passengers survived, and 61.6% perished.
- **Gender:** Gender was the strongest factor. 74.2% of women survived, compared with 18.9% of men.
- **Socioeconomic status:** Survival fell with ticket class. 63.0% of First Class passengers survived, versus 47.3% in Second Class and 24.2% in Third Class.
- **Class and gender together:** Women in First Class had a 96.8% survival rate. Women in Third Class (50.0%) still survived more often than men in First Class (36.9%).
- **Fare:** Higher fares were associated with higher survival, which likely reflects cabins closer to the boat deck.
- **Age:** Children aged 0–12 had the highest survival rate among age groups (58.0%). Passengers aged 60 and over had the lowest (22.7%).

## Dataset

The project uses the Titanic training data (`train.csv`) from the [Kaggle "Titanic – Machine Learning from Disaster"](https://www.kaggle.com/c/titanic) competition. It contains 891 passengers and 12 columns:

| Column | Description |
|---|---|
| `PassengerId` | Unique passenger identifier |
| `Survived` | Survival outcome (0 = perished, 1 = survived) |
| `Pclass` | Ticket class (1, 2, or 3) |
| `Name` | Passenger name |
| `Sex` | Passenger sex |
| `Age` | Age in years |
| `SibSp` | Number of siblings or spouses aboard |
| `Parch` | Number of parents or children aboard |
| `Ticket` | Ticket number |
| `Fare` | Passenger fare |
| `Cabin` | Cabin number (mostly missing) |
| `Embarked` | Port of embarkation (C, Q, or S) |

The raw data has missing values in `Age` (177 rows), `Cabin` (687 rows), and `Embarked` (2 rows).

The dataset is not modified in place. The cleaned output is written to a separate file.

## Getting Started

### Prerequisites

- Python 3.10 or newer (the code uses `match` statements)
- pip

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Omid-Zamzami/Titanic-EDA.git
   cd Titanic-EDA
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS / Linux
   source .venv/bin/activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Make sure `train.csv` is in the `data/` folder.

## Usage

Run the cleaning pipeline and visualizer from the project root:

```bash
python src/clean_data.py
```

To use a different CSV file located in `data/`, pass its name with `-f` or `--file`:

```bash
python src/clean_data.py --file my_data.csv
```

The script:

1. Loads the raw CSV from `data/`.
2. Cleans it and saves the result as `data/cleaned_<filename>`.
3. Opens an interactive menu:

```
Titanic EDA Visualizer
1) Overall Survival
2) Gender Survival
3) Class Survival
4) Age Distribution
5) Fare Distribution
6) Multivariate (Class & Sex)
7) Correlation Heatmap
0) Exit
```

Each option opens a matplotlib window. Close the window to return to the menu.

## Running the Tests

The test suite uses [pytest](https://docs.pytest.org/). It runs headless, so plots are not displayed during testing.

```bash
pytest -v
```

The tests cover:

- Command-line argument parsing
- File loading and saving, including error cases
- Schema validation
- Imputation of `Age` and `Embarked`, including fallback behaviour
- Cabin feature engineering, including a fully empty `Cabin` column
- Age-group and fare-quartile binning
- The full cleaning pipeline and its immutability guarantees
- Every plotting function
- Menu navigation and invalid input handling
- An end-to-end run of `main()`

The `pytest.ini` file sets `pythonpath = .` so that tests can import from `src/`.

## Data Cleaning Pipeline

The `cleaner()` function runs these steps in order on a copy of the input:

1. **Validation:** Checks that all required Titanic columns are present.
2. **Deduplication:** Removes exact duplicate rows.
3. **`Embarked` imputation:** Fills missing ports with the most frequent port (mode).
4. **`Age` imputation:** Fills missing ages with the median age of the same `Pclass` and `Sex` group. If a group has no known ages, the overall median of the known ages is used.
5. **Cabin feature engineering:**
   - `Has_Cabin`: 1 if a cabin was recorded, otherwise 0.
   - `Deck`: the first letter of the cabin, or `Unknown`.
   - The raw `Cabin` column is then dropped.

The result has no missing values.
